# 🚀 콘솔 기반 로또 게임

## 기능 요구사항 요약

- 로또 번호 범위: 1 ~ 45
- 당첨 정보
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 입력: 로또 구입 금액, 6개 로또 번호, 1개 보너스 번호
- 출력: 발행한 로또 수량 및 번호, 당첨 내역, 수익률

## 기능 목록

> 로또 한 개를 발행하고 당첨 번호와 비교해서 몇 개가 일치하는지

로또의 기능을 한줄 정리하고 아래와 같이 세부 기능을 나눴습니다.

로또 발행

- [ ] 구매 금액에 따른 발행할 로또 수 계산
- [ ] 1-45 값 중 중복되지 않는 수 6개 뽑기
- [ ] 개수만큼 발행하기 (초기 1개)

당첨 번호와 비교

- [x] 당첨번호와 일치하는 개수 계산
- [ ] 5개가 일치할 때, 보너스 번호 보유 여부

당천 결과 계산

- [ ] 당첨 통계 계산
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
    위 기준에 맞춰 등수 및 당첨금 추출

- [ ] 수익률 계산 (액첨금액/구매금액 \* 100)
