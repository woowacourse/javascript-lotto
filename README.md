# 로또

## 기능요구사항

- [] 당첨 번호, 로또 번호 비교
    - [x] 로또 생성
        - [x] 구입금액 입력
            - [x] 재입력
    - [x] 당첨 번호, 보너스 번호 입력
        - [x] 재입력
    - [] 통계
        - [x] 로또 매칭 결과 계산
        - [x] 총금액 계산
        - [] 수익률 계산
    - [x] 출력
        - [x] 로또 구입갯수 출력
        - [x] 로또 번호 출력
        - [x] 당첨 결과 출력
        - [] 수익률 출력

## 입력 예외 상황
 - [x] 구입금액
    - [x] 1000미만 입력 예외
    - [x] 정수가 아닌 입력 예외

- [x] 당첨 로또번호
    - [x] 1 ~ 45 이내가 아닌 입력 예외
    - [x] 겹치는 번호 입력 예외

- [x] 보너스 로또번호
    - [x] 1 ~ 45 이내가 아닌 입력 예외
    - [x] 당첨 로또번호와 겹치는 입력 예외

# 로또 웹으로 구현하기

## 기능 요구 사항

- [x] 레이아웃
  - [x] 네비게이션 바
  - [x] 메인 컨텐츠 영역
    - [x] 구입할 금액 입력 폼
    - [x] 구입한 로또 번호
    - [x] 당첨번호 + 보너스 번호 입력 폼
  - [x] 푸터
  - [x] 당첨번호 + 보너스 번호 입력 폼이 로또를 구매헀을때 렌더링
  - [x] 모달
    - [x] 당첨 통계
    - [x] 다시 시작하기 버튼

  - [x] 동작
    - [x] 입력
      - [x] 입력 에러 메시지 노드 추가
      - [x] 입력 성공 이펙트 추가
    - [x] 로또 구입 금액 전달 처리
      - [x] 로또 구입 검증
    - [x] 당첨 번호, 보너스 번호 전달 처리
      - [x] 당첨 번호 검증
      - [x] 보너스 번호 검증
      - [x] 우승 로또 생성
      - [] 당첨 통계 계산
    - [x] 재시작

## 리팩토링 사항

- components
  - [x] 구매한 로또 목록 컴포넌트
  - [x] 구매한 로또 갯수 컴포넌트
  - [x] 당첨 결과 테이블 컴포넌트
  - [x] 수익률 메시지 컴포넌트
  - [x] 재시작 버튼 컴포넌트

- view
  - [x] 구매한 로또 콘텐츠 렌더링
  - [x] 결과 테이블, 수익률, 재시작 -> 모달 렌더링
  - [x] 에러 메시지 렌더링
  - [] 입력 성공 렌더링
  - [] hidden 유틸
  - [] 모달 close/open
  - [] 재시작

- controller
  - [] 로또 구매 금액 입력 처리
  - [] 당첨번호, 보너스 번호 입력 처리
  - [] 재시작

- index.js
  - [] 즉시실행함수 정리
