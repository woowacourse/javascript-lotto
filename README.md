# 2단계 - 웹 기반 로또 게임

## 학습 목표

- UI와 도메인 영역을 분리할 수 있는 설계를 고민해보고, 목적에 맞게 객체와 함수를 활용
- 단위 테스트 기반으로 점진적인 리팩터링

## 프로그래밍 요구사항

- [x] 1단계에서 구현한 도메인 로직을 (최대한) 수정하지 않고, UI만 변경한다.
- [x] 목적에 맞는 HTML 태그를 사용한다.
- [x] CSS 속성 선언 순서의 일관성을 고려한다.
- [x] CSS 속성은 가능한 한 축약형(shorthand)을 사용한다.
- [x] flexbox를 활용해 레이아웃을 구성한다.

## CSS 속성 선언 순서

1. `display` - 표시(관련 속성: visibility)
2. `overflow` - 넘침
3. `float` - 흐름(관련 속성: clear)
4. `position` - 위치(관련 속성: top, right, bottom, left, z-index)
5. `width & height` - 크기
6. `margin & padding` - 간격
7. `border` - 테두리
8. `background` - 배경
9. `font` - 폰트(관련 속성: color, letter-spacing, text-align, text-decoration, text-indent vertical-align, white-space 등)
10. `animation` - 동작(관련 속성: animation, transform, transition, marquee 등)

## 기능 목록

### [로또 구매]

#### UI

- 구입 금액을 입력빋는다.
- 구입 버튼을 클릭한다.
- 예외 발생시 에러 메시지 창을 띄운다.

#### DOMAIN

- 구입 금액
  - [예외] 빈 값인 경우
  - [예외] 문자가 포함된 경우
  - [예외] 1,000원 단위가 아닌 경우
  - [예외] 0 이하인 경우

### [로또 발행]

#### UI

- 사용자가 로또 구입에 성공한 이후에만 발행 로또가 표시된다.
- 구매 수량만큼 로또 번호를 표시한다.

#### DOMAIN

- 로또 구입 수량을 계산한다.
- 구입 수량만큼 로또 번호를 무작위로 6개씩 생성한다.
- 생성된 번호를 오름차순 정렬한다.
- 구입 수량만큼 로또를 발행한다.

### [당첨 로또 발행]

#### UI

- 사용자가 로또 구입에 성공한 이후에만 발행 로또가 표시된다.
- 당첨 번호를 입력받는다.
- 보너스 번호를 입력받는다.
- 결과 확인하기 버튼을 클릭한다.
- 예외 발생시 에러 메시지 창을 띄운다.

#### DOMAIN

- 당첨 번호
  - [예외] 빈 값인 경우
  - [예외] 문자가 포함된 경우
  - [예외] 당첨 번호가 0또는 음의 정수인 경우
  - [예외] 당첨 번호가 1~45 사이가 아닌 경우
  - [예외] 당첨 번호가 중복되는 경우
  - [예외] 당첨 번호가 6개가 아닌 경우

- 보너스 번호
  - [예외] 빈 값인 경우
  - [예외] 문자가 포함된 경우
  - [예외] 보너스 번호가 0또는 음의 정수인 경우
  - [예외] 보너스 번호가 1~45 사이가 아닌 경우
  - [예외] 보너스 번호가 당첨 번호와 중복되는 경우

### [당첨 통계]

#### UI

- 사용자가 결과 확인에 성공한 경우에만 표시된다.
- 모달창으로 표시된다.
- 창닫기 버튼을 눌러 창을 닫는다.
- 일치 개수, 당첨금, 당첨 개수와 수익률을 표시한다.
- 다시 시작하기 버튼을 클릭한다.

#### DOMAIN

- 구매한 모든 로또의 등수를 계산한다.
- 수익률을 계산한다.
  - 소숫점 둘째자리에서 반올림
- 프로그램을 처음부터 다시 시작한다.
