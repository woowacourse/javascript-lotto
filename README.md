# 🚀 웹 기반 로또 게임

이전 단계에서 구현한 콘솔 기반의 도메인 로직을 최대한 유지하면서 웹 UI를 추가한 했습니다.

## 기능 요구사항 요약

- 로또 번호 범위: 1 ~ 45
- 당첨 정보
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 입력: 로또 구입 금액, 6개 로또 번호, 1개 보너스 번호
- 출력: 발행한 로또 수량 및 번호, 당첨 내역, 수익률

## 기본 레이아웃 구조

header, main, footer로 구성하기

- header
  - 로또 로고와 게임 제목
- main
  - 구입 금액 입력 섹션
  - 구매한 로또 번호 출력 영역
  - 당첨 번호 및 보너스 번호 입력 섹션
  - 결과 확인 버튼
- footer
  - 'Copyright 2023. woowacourse' 카피라이터
