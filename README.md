# 로또 게임

## 소개
step1에서 만든 콘솔 기반 로또 게임을 실제 웹 UI에 적용해 보았습니다.
주제가 TDD인 만큼, 콘솔 테스트와 더불어 웹 테스트도 TDD 방식으로 구현하고자 하였습니다.

## UI 시나리오
1. 구입 금액을 `input`에 작성한다.
2. 구입 `button`을 누른다.
3. 내가 구매한 로또가 하단에 나온다.
4. 구매한 로또 리스트 아래에 당첨번호 6개와 보너스 번호 1개를 적는다.
5. 결과 확인하기 `button`을 누른다.
6. 당첨 통계가 모달로 나온다.
7. 해당 모달에서 다시 시작하기 `button`을 누른다.
8. 1번부터 과정을 다시 시작한다.

## 에러 처리
### 구입 금액
구입 금액을 입력 후, 구입 버튼을 눌렀을 때, 구입 금액에 관한 에러 메시지는 구입 금액 `input` 아래에 메시지를 띄운다.
### 당첨 번호, 보너스 번호
당첨 번호와 보너스 번호를 입력 후, 결과 확인하기 버튼을 눌렀을 때, 당첨 번호와 보너스 번호에 관한 에러 메시지는 당첨 번호 `input`아래에 메시지를 띄운다.

## UI 테스트 목록
- [ ] 구입 금액을 입력하고 구입 버튼을 누르면 랜덤 로또 번호 리스트, 당첨 번호 입력, 보너스 번호 입력, 결과 확인하기 버튼이 나온다.
- [ ] 당첨 번호와 보너스 입력을 입력한 후, 결과 확인하기 버튼을 누르면 당첨 통계 모달이 나온다.
- [ ] 당첨 통계에 있는 다시 시작하기 버튼을 누르면 랜덤 로또, 당첨 번호, 보너스 번호가 초기화되고 처음 구입 금액 입력이 나온다.

## 기능 요구 사항

### 로또 번호

- [x] 번호는 6개로 한다.
- [x] 구입금액은 1000원 단위로 한다.
- [x] 구입금액에 따라 로또 번호를 랜덤으로 발급한다.
- [x] 로또 번호의 범위는 1 ~ 45로 한다.
- [x] 로또 번호는 오름차순으로 정렬한다.

### 당첨 번호

- [x] 당첨 번호 6개와 보너스 번호 1개로 구성된다.
- [x] 당첨 번호의 범위는 1 ~ 45로 한다.
- [x] 당첨 번호는 콤마(,)로 분리한다.

### 비교

- [x] 6개 번호 일치 시 1등
- [x] 5개 번호 일치 + 보너스 번호 일치 시 2등
- [x] 5개 번호 일치 시 3등
- [x] 4개 번호 일치 시 4등
- [x] 3개 번호 일치 시 5등

### 통계

- [x] 1등 : 2,000,000,000
- [x] 2등 : 30,000,000
- [x] 3등 : 1,500,000
- [x] 4등 : 50,000
- [x] 5등 : 5,000
- [x] 수익률 계산은 소수점 첫째 자리까지 표시한다.

### 입력

- [x] 구입금액
- [x] 당첨 번호
- [x] 보너스 번호
- [x] 재시작 여부

### 출력

- [x] 발급받은 로또 번호
- [x] 당첨 통계

### 재시작 여부

- [x] 재시작 여부 입력 시, y 또는 Y를 입력하면 초기화하고 구입 금액부터 다시 받는다.
- [x] 재시작 여부 입력 시, n 또는 N를 입력하면 종료한다.

## 예외 처리

### 구입 금액

- [x] 1000원 미만일 때, 재입력 받는다.
- [x] 숫자가 아닐 시, 재입력 받는다.
- [x] 1,000원 단위가 아닐 시, 재입력 받는다.

### 당첨 번호

- [x] 당첨 번호가 6개가 아닐 시, 재입력 받는다.
- [x] 번호 범위가 1 ~ 45가 아닐 시, 재입력 받는다.
- [x] 콤마(,) 이외의 문자를 입력 시, 재입력 받는다.
- [x] 콤마(,) 사이 숫자가 입력되지 않을 시, 재입력 받는다.

### 보너스 번호

- [x] 당첨 번호가 중복 시, 재입력 받는다.
- [x] 번호 범위가 1 ~ 45가 아닐 시, 재입력 받는다.
- [x] 숫자가 아닐 시, 재입력 받는다.

### 재시작 입력

- [x] y / Y / n / N 이외를 입력 시, 재입력 받는다.
