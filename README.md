# 로또

## 기능요구사항

- [] 당첨 번호, 로또 번호 비교
    - [x] 로또 생성
        - [x] 구입금액 입력
            - [x] 재입력
    - [] 당첨 번호, 보너스 번호 입력
        - [] 재입력
    - [] 통계
        - [] 수익률 계산
    - [] 출력
        - [] 수익률 출력

## 입력 예외 상황
 - [x] 구입금액
    - [x] 1000미만 입력 예외
    - [x] 정수가 아닌 입력 예외

- [] 당첨 로또번호
    - [] 1 ~ 45 이내가 아닌 입력 예외
    - [] 겹치는 번호 입력 예외

- [] 보너스 로또번호
    - [] 1 ~ 45 이내가 아닌 입력 예외
    - [] 당첨 로또번호와 겹치는 입력 예외
