# 콘솔 기반 로또 게임

## 출력 에시

```
> 구입금액을 입력해 주세요.8000
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

> 당첨 번호를 입력해 주세요. 1,2,3,4,5,6

> 보너스 번호를 입력해 주세요. 7

당첨 통계
--------------------
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.

> 다시 시작하시겠습니까? (y/n)

```

## 기능 요구 사항

### 로또 번호

- [x] 번호는 6개로 한다.
- [x] 구입금액은 1000원 단위로 한다.
- [x] 구입금액에 따라 로또 번호를 랜덤으로 발급한다.
- [x] 로또 번호의 범위는 1 ~ 45로 한다.
- [x] 로또 번호는 오름차순으로 정렬한다.

### 당첨 번호

- [x] 당첨 번호 6개와 보너스 번호 1개로 구성된다.
- [x] 당첨 번호의 범위는 1 ~ 45로 한다.
- [x] 당첨 번호는 콤마(,)로 분리한다.

### 비교

- [x] 6개 번호 일치 시 1등
- [x] 5개 번호 일치 + 보너스 번호 일치 시 2등
- [x] 5개 번호 일치 시 3등
- [x] 4개 번호 일치 시 4등
- [x] 3개 번호 일치 시 5등

### 통계

- [x] 1등 : 2,000,000,000
- [x] 2등 : 30,000,000
- [x] 3등 : 1,500,000
- [x] 4등 : 50,000
- [x] 5등 : 5,000
- [x] 수익률 계산은 소수점 첫째 자리까지 표시한다.

### 입력

- [x] 구입금액
- [x] 당첨 번호
- [x] 보너스 번호
- [x] 재시작 여부

### 출력

- [x] 발급받은 로또 번호
- [x] 당첨 통계

### 재시작 여부

- [x] 재시작 여부 입력 시, y 또는 Y를 입력하면 초기화하고 구입 금액부터 다시 받는다.
- [x] 재시작 여부 입력 시, n 또는 N를 입력하면 종료한다.

## 예외 처리

### 구입 금액

- [x] 1000원 미만일 때, 재입력 받는다.
- [x] 숫자가 아닐 시, 재입력 받는다.
- [x] 1,000원 단위가 아닐 시, 재입력 받는다.

### 당첨 번호

- [x] 당첨 번호가 6개가 아닐 시, 재입력 받는다.
- [x] 번호 범위가 1 ~ 45가 아닐 시, 재입력 받는다.
- [x] 콤마(,) 이외의 문자를 입력 시, 재입력 받는다.
- [x] 콤마(,) 사이 숫자가 입력되지 않을 시, 재입력 받는다.

### 보너스 번호

- [x] 당첨 번호가 중복 시, 재입력 받는다.
- [x] 번호 범위가 1 ~ 45가 아닐 시, 재입력 받는다.
- [x] 숫자가 아닐 시, 재입력 받는다.

### 재시작 입력

- [x] y / Y / n / N 이외를 입력 시, 재입력 받는다.
