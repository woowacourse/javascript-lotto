### 입력 처리

- [ ] 로또 프로그램 진행을 위한 정보를 입력받는다.
  - `Console.readLineAsync()`를 활용하여 입력받는다.
  - "구입금액을 입력해 주세요."라는 문구로 로또 구입 금액을 입력받는다.
  - "당첨 번호를 입력해 주세요."라는 문구로 당첨 번호를 입력 받고 번호는 쉼표(,)를 기준으로 구분한다.
  - "보너스 번호를 입력해 주세요."라는 문구로 보너스 번호를 입력 받는다.
  - 사용자가 잘못된 값을 입력할 경우 에러를 발생시킨 후 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.
  - 재시작/종료 여부를 입력받는다.

### 파싱

- [ ] 사용자 입력 파싱
  - 사용자가 입력한 금액을 숫자로 파싱한다.
  - 사용자 입력으로 생성된 당첨 번호를 `[number1, number2, number3, number4, number5, number6]`과 같은 형식으로 파싱한다.
  - 사용자에게 입력받은 보너스 번호를 숫자로 파싱한다.
  - 사용자에게 입력받은 재시작/종료 여부 값을 소문자로 파싱한다.

### 입력 검증

- [ ] 구입 금액 입력 검증
  - 입력값이 비어 있으면 [ERROR] 구입금액을 입력해주세요.
  - 숫자로 변환할 수 없는 경우 [ERROR] 구입금액은 숫자만 입력 가능합니다.
  - 0 이하의 값일 경우 [ERROR] 구입금액은 양수만 입력 가능합니다.
  - 1,000원 단위로 나누어떨어지지 않으면 [ERROR] 구입금액은 1,000원 단위로 입력해야합니다.
- [ ] 당첨 번호 입력 검증
  - 입력값이 비어 있으면 [ERROR] 당첨 번호를 입력해주세요.
  - 쉼표(,)로 구분되지 않은 경우 [ERROR] 당첨 번호는 쉼표(,)로 구분해주세요
  - 6개의 숫자가 아닐 경우 [ERROR] 당첨 번호는 6개의 숫자로 이루어져야합니다
  - 숫자가 아닌 값이 포함된 경우 [ERROR] 당첨 번호는 숫자만 입력 가능합니다.
  - `1 ~ 45` 범위를 벗어나면 [ERROR] 당첨 번호는 1~45 사이의 숫자로 입력해주세요
  - 중복된 숫자가 있을 경우 [ERROR] 당첨 번호는 중복되지 않아야합니다.
- [ ] 보너스 번호 입력 검증
  - 입력값이 비어 있으면 [ERROR] 보너스 번호를 입력해주세요.
  - 숫자로 변환할 수 없는 경우 [ERROR] 보너스 번호는 숫자만 입력 가능합니다.
  - `1 ~ 45` 범위를 벗어나면 [ERROR] 보너스 번호는 1~45 사이의 숫자로 입력해주세요
  - 당첨 번호와 중복될 경우 [ERROR] 보너스 번호는 당첨 번호와 중복되지 않아야합니다.
- [ ] 재시작/종료 여부 입력 검증
  - y/n이 아닌 경우 [ERROR] y/n이 아닌 문자는 입력할 수 없습니다.

### 비즈니스 로직

- [ ] 구입 개수를 전달받으면 개수에 해당하는 만큼 로또를 발행한다.
- [ ] 사용자가 구매한 로또 번호와 당첨 번호를 비교한다. <- 이놈이 번개
  - [ ] 당첨 내역을 계산한다
  - [ ] 수익률을 계산한다.

### 출력 처리

- [ ] 구입 금액에 따른 로또 개수 출력
  - `${n}개를 구매했습니다.`
- [ ] 구입 로또 번호 오름차순으로 출력
  - `[number1, number2, number3, number4, number5, number6]`
- [ ] 당첨 통계 출력

  - [ ] 수익률 출력
    - `총 수익률은 ${f}%입니다.`

- [x] 구매한 로또 번호와 당첨 번호 비교

  - [1,2,3,4,5,6] vs [1,2,3,4,5,6], 보너스 7 → 1등 (6개 일치)
  - [1,2,3,4,5,7] vs [1,2,3,4,5,6], 보너스 7 → 2등 (5개 + 보너스 일치)
  - [1,2,3,4,5,7] vs [1,2,3,4,5,6], 보너스 9 → 3등 (5개 일치)
  - [1,2,3,4,7,8] vs [1,2,3,4,5,6], 보너스 7 → 4등 (4개 일치)
  - [1,2,3,7,8,9] vs [1,2,3,4,5,6], 보너스 7 → 5등 (3개 일치)
  - [1,2,7,8,9,10] vs [1,2,3,4,5,6], 보너스 7 → 낙첨 (2개 일치)
  - [1,7,8,9,10,11] vs [1,2,3,4,5,6], 보너스 7 → 낙첨 (1개 일치)
  - [7,8,9,10,11,12] vs [1,2,3,4,5,6], 보너스 7 → 낙첨 (0개 일치)

- [x] 당첨 내역 반환
  - 당첨 번호가 [1,2,3,4,5,6], 보너스 번호가 7일 때
    - [[1,2,3,4,5,6], [1,2,3,4,5,7], [1,2,3,4,5,8] [1,2,3,4,7,9], [1,2,3,8,9,10], [1,7,8,9,10,11], [1,2,3,4,5,6]]
      => [0, 2, 1, 1, 1, 1]
  - 당첨 번호가 [1,2,3,4,5,6], 보너스 번호가 7일 때
    - [[7, 8, 9, 10, 11, 12], [7, 8, 9, 10, 11, 13], [7, 8, 9, 10, 11, 14], [7, 8, 9, 10, 11, 15], [7, 8, 9, 10, 11, 12]]
      => [0, 0, 0, 0, 0, 0]
