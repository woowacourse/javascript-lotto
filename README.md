# 로또

## 기능요구사항

- [] 당첨 번호, 로또 번호 비교
    - [x] 로또 생성
        - [x] 구입금액 입력
            - [x] 재입력
    - [x] 당첨 번호, 보너스 번호 입력
        - [x] 재입력
    - [] 통계
        - [x] 로또 매칭 결과 계산
        - [] 수익률 계산
    - [x] 출력
        - [x] 로또 구입갯수 출력
        - [x] 로또 번호 출력
        - [] 당첨 결과 출력
        - [] 수익률 출력

## 입력 예외 상황
 - [x] 구입금액
    - [x] 1000미만 입력 예외
    - [x] 정수가 아닌 입력 예외

- [x] 당첨 로또번호
    - [x] 1 ~ 45 이내가 아닌 입력 예외
    - [x] 겹치는 번호 입력 예외

- [x] 보너스 로또번호
    - [x] 1 ~ 45 이내가 아닌 입력 예외
    - [x] 당첨 로또번호와 겹치는 입력 예외
