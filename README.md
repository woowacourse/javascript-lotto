# 1단계 - 콘솔 기반 로또 게임

## 구현할 기능 목록

### Domain

#### Lotto

- 양수 6개를 가진다
- 번호는 1~45 사이의 숫자여야 한다
- 번호는 중복되지 않아야 한다
- 번호는 오름차순으로 정렬된 상태로 저장된다
- 특정 번호가 포함되어 있는지 확인한다

#### WinningNumber

- Lotto 객체와 양수인 보너스 번호를 입력받는다
- 보너스 번호는 당첨 번호와 중복되지 않아야 한다
- 보너스 번호는 1~45 사이의 숫자여야 한다
- 구매 로또와 비교하여 일치 개수와 보너스 일치 여부를 반환한다

#### Money

- 양수인 구매 금액을 입력받는다
- 구매 금액이 1,000원 미만이면 예외를 발생시킨다
- 구매 금액이 1,000원으로 나누어 떨어지지 않으면 예외를 발생시킨다
- 구매 가능한 로또 개수를 반환한다

#### Rank

- 일치 개수와 보너스 일치 여부를 받아 등수를 반환한다

#### LottoMachine
- 로또를 반환한다

#### LottoResult

- 등수별 당첨 개수를 집계한다
- 수익률을 계산한다


#### validator

- 구입 금액 입력값 형식을 검증한다
- 당첨 번호 입력값을 파싱 후 검증하고, 검증 완료 시 변환하여 반환한다
- 보너스 번호 입력값 형식을 검증한다
- 재시작 입력값이 y/n인지 검증한다

### Controller

- 로또 구매 흐름을 제어한다
- 구매한 로또 목록을 출력한다
- 당첨 번호와 보너스 번호를 입력받는다
- 당첨 통계와 수익률을 출력한다
- 재시작/종료를 처리한다
