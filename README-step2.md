## 요구 사항

- [x] figma 시안을 기준으로 구현한다.
- [x] 실행 가능한 페이지에 접근할 수 있도록 GitHub Pages 기능을 이용하고, 해당 링크를 PR과 README에 작성한다.
- [x] 예측 가능하고, 실수를 방지할 수 있는 코드를 작성하기 위해 노력한다.

- [x] CSS 문법 사용에 익숙해진다.
