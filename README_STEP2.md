# 2단계 - 웹 기반 로또 게임 구현 기능 목록
1. [x] 공통 css 지정 
    - 폰트
    - 색상
2. [ ] UI 구성
    1. [x] 헤더에 스타일 적용
        - 높이, 색
    2. [x] 푸터 copyright 작성, 스타일 적용
    3. [X] 구입 전
        - [x] 타이틀
        - [x] 구입할 금액 입력해주라는 텍스트
        - [x] 구입 금액 입력 칸
        - [] 에러 메세지 보여주 곳
        - [x] 구입 버튼
    4. [ ] 구입 후 
        - 구입 전 구성 요소는 그대로
        -  몇 개 구입했는지 알려주는 텍스트
        - 구입한 로또 번호 출력
        - 지난 주 당첨 번호 6개와 보너스 번호 1개를     입력해주라는 텍스트
        - 당첨 번호, 보너스 번호 각 입력 칸 위에 텍스트
        - 당첨 번호 입력 칸 6개(1개의 숫자를 입력할 수  있는   칸 6개)
          - 입력 칸 밑에 에러 메세지 보여주는 텍스트
        - 보너스 번호 입력 칸 1개
          - 입력 칸 밑에 에러 메세지 보여주는 텍스트
        - 결과 확인하기 버튼
    5. [ ] 당첨 통계 모달
        - 당첨 모달을 닫을 수 있는 `X`버튼
        - 당첨 통계 타이틀
        - 일치 갯수, 당첨금, 당첨 갯수를 알려주는 표
        - 수익률을 알려주는 텍스트
        - 다시 시작하기 버튼

3. 동작 구성
      1. [ ] 구입 전
          - 구입 금액을 입력
          - 구입 버튼을 클릭
            - 구입 금액을 검증한다
              - 에러 메세지는 입력 칸 밑에 보이도록
            - 구입 금액 입력 칸을 비운다
            - 구입 후 단계로 이동
      2. [ ] 구입 후
          - 몇 개 구입했는지 알려주는 텍스트 출력
          - 구입한 로또 번호 출력
          - 지난 주 당첨 번호 6개와 보너스 번호   1개를     입력해주라는 텍스트 출력
          - 당첨 번호, 보너스 번호 각 입력 칸 위에  텍스트   출력
          - 당첨 번호 입력 칸 6개(1개의 숫자를 입력할 수    있는   칸 6개) 생성
          - 보너스 번호 입력 칸 1개 생성
          - 당첨 번호입력 
          - 보너스 번호를 입력 
          - 결과 확인하기 버튼 클릭
            - 당첨 번호 검증
              - 에러 메세지는 입력 칸 밑에 출력
            - 보너스 번호 검증
              - 에러 메세지는 입력 칸 밑 출력
            - 당첨 통계 모달 화면으로 이동
      3. [ ] 당첨 통계 모달
            - `X` 버튼을 누르면 모달을 닫고, 이전     화면으로    돌아간다
            - 당첨 통계 타이틀 출력
            - 일치 갯수, 당첨금, 당첨 갯수를 알려주는 표    출력
            - 수익률을 알려주는 텍스트 출력
            - 다시 시작하기 버튼 클릭
              - 구입 전 화면으로 돌아간다.
