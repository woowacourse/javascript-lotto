### 도전해볼 기능
- [x] 발행된 로또 더보기 기능(기본 10개)
1. 반복문으로 생성되는 각 로또들의 클래스(lotto-item)를 센다.
2. 10개 초과면 더보기 버튼을 보이게하고 10개까지만 로또를 보인다.
.lotto-item:nth-child(n+11) 
-> css 가상 클래스 선택자: 알아서 n값에 0부터 1씩 증가시키며 대입해주는 루프 변수
3. 더보기 버튼을 누르면 나머지 로또들을 전부 보이게한다.
4. 더보기버튼을 접기버튼으로 바꾸고 접기 버튼을 누르면 초기형태로 되돌아간다.
